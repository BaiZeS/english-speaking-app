# 使用指南 · English Assistant v2.2.0

> 15 秒版：每天 10 分钟——跟着**任务通关课**把真实场景（英文会议/汇报/谈判）练到敢开口，AI 会像真人一样追问；**5 分钟 CEFR 测评**定级，之后**每次练习都会更新你的能力画像**，进步看得见。

## 安装升级（一次性）

旧版（1.4.0 等）收不到 OTA 提示属预期——装一次新包即可，此后自动更新：
1. 手机浏览器打开（或在 GitHub Releases 页找 `v2.2.0`）：
   `https://github.com/BaiZeS/english-speaking-app/releases/download/v2.2.0/EnglishAssistant-2.2.0.apk`
2. 安装时允许「未知来源」。首次启动不需要任何设置，直接可用。
3. 之后开 App 若提示新版本 → 点更新 → 下载走服务器加速（不再是 GitHub 龟速），装完即最新版。

> **v2.2.0 是一次强制升级**：这一版把"收工出总评"的接口改了（见 CHANGELOG），旧包（≤2.1.0）留在服务器上会看到收工后复盘页是空的，所以服务器端把最低支持版本设成了 2.2.0——弹出来的升级提示**不能**再点「稍后再说」绕过。请直接从 App 内更新，或按上面第 1 步手动装一次；此后回到正常的"可推迟"节奏。

## 两种录音手势（v2.2.0 起，说清楚哪个面按哪种）

一句话能录完的面是**长按**，一整段连续取句的面是**点按**——这不是随手混用，是照取句长短分的：按住十几秒不放来录完整篇课文，谁的手都会抖。

| 手势 | 哪些屏 | 怎么用 |
|---|---|---|
| **长按**（按住说话 · 松开发送）| 打基础、实战对话、跟读练课、角色对话、弱词本、测评朗读题 | **按住即开始录**（键变红、出现 Stop 图标），**松手即停止并提交**。按住期间不用管它，不会有"既已开始又已结束"的错乱。 |
| **点按**（点一下开始 · 再点一下结束）| 影子跟读、自由对话 | 点一下开始整段录音，再点一下结束并提交。旁边**实时显示已经录了多久**（`mm:ss`）。自由对话有 30 秒上限，快到点会先提示「即将自动发送」，到点自动发出；影子跟读录整篇，**没有秒数上限**，所以你什么时候点结束都可以。 |

两类面在录音时都有一条**从右往左滚的波形**：每根小条就是你嗓子里那一帧的音量，说完能看到自己哪里冲、哪里含糊。松手后**这一条形状会留在屏幕上**，直到分数回来——不再一松手界面就空了，也不会有那种"坐在那儿不动"的样子。

## 首页（4 个 Tab 之一：首页 / 课程 / 词汇 / 我的）

- **未测评前**：置顶一张「5 分钟测出你的英语水平」引导卡 → 先点它（7 题：跟读/复述/翻译/开放问答，可录音可打字，约 1-2 分钟判级）。定级 A1-C2 + 四维雷达，存到「我的」。
- **继续学习**：上次没练完的课一键续上（崩溃/切后台也不怕）。
- **最近复盘**：旁边那颗就是"我刚练完那一场的复盘报告"（v2.2.0 新增；以前练完退出就再也点不回去，只会新开一局——详见下面「练完还想再看那份报告」）。
- **今日推荐**：自动挑你最弱维度的课。
- **生成我的专属课**：场景画廊入口旁最显眼那张卡。点进去**用一句话说目标**（如「下周主持项目进度会」），进度动画约 3-8 分钟（服务器免费额度限速，泡杯茶回来就在了），生成后进你的课程列表可反复练、可删。
- **场景画廊**：日常交流 / 职场商务 / 考试面试 / 旅行出国 → 8 门人工精编情景课（咖啡店点单、英文项目汇报、协商交付日期、EMBA 面谈…），卡片上有时长/任务数/通关徽章。

## 一门情景课怎么走（核心玩法，约 8-12 分钟）

1. **打基础**：6 步小题——跟读（读句子打分）、复述（用英文总结）、翻译（中译英）、造句（用核心词造一句）。可以跳过 ≤2 步。

   **每一题答完立刻给你看结果**（v2.2.0 起，以前只有不及格时才露面）：总分 + **五个维度**（发音 / 流利 / 完整 / 语法 / 词汇——这一维没证据就不画，不会被当成 0 分）+ **逐词芯片（带音标）** + **引擎实际听到的那句原文** + 中文建议 + 说对的要点与踩的坑。
   - **85 分以上**：小字提示"5 秒后自动继续 · 点按可停留"，5 秒后自动进下题。**想多看一会儿就滚一下或点一下屏幕任意处，倒计时立刻取消**，改成你自己点「继续」。
   - **60-84 分**：一定等你读完中文建议再手动前进——这个分数带恰恰是最该把建议读完的时候。
   - **不到 60 分**：这一步还在，可以直接「再试一次」刷高分。
   - 中途退出没关系，重进这节课时**已经答过的题的反馈还在**（服务端一直存着每步最近那次评分）。顶部的进度点上也直接印着每步的分数。
2. **任务实战**（像微信聊天）：AI 扮演客户/面试官/老板，**你的屏幕顶部挂着任务清单**（如「问到 deadline」「顶住提前 3 天的压力」「给出可行方案」）——没做到会追问你，做完自动打勾；全部勾完才算**通关**。说得不标准/不地道时，你消息下方冒出「让这句更地道」→ 展开看到**原话 vs 地道说法**对照，点 ⭐ 收进表达库。卡壳点「要提示」拿示范句（会计入复盘评价）。轮次到了自动收工。实战的每条语音回答下面也带一条**紧凑的发音读数**（有证据的维度分 + 语速 + 哪几个词没读准；纯打字回答那一轮没有发音证据，就不画这一条）。
3. **复盘报告**：总分 + 发音/语法/词汇/流利度四维进度条（只平均**可信**评分，降级分不混进来）+ 「能力画像 +x.x」增量 + 你的亮点句 / 建议改进 + 每句「你当时说的 vs 更好的说法」+ 参考剧本（可播标准音再学一遍）。有中断的课下次进会弹「上次练了 4 步 / 任务完成 1/4？」一键接上。
   - **收工后不会再转圈了**。点「收工」（或聊到轮次上限自动收工）**立刻**跳进复盘页：总分圆环、四维、任务清单、逐句对照、生词这些**数字**在收工那一刻就算完并存好了；只有那两句 AI 评语的位置先写着「**AI 正在写总评…**」，隔几十秒自己补齐（页面会自动刷，不用你手动退出重进）。
   - 评语**不会永远不来**：写完就是最终态；写失败时给一句可重试的错误，而不是让你对着一页干等。总之要说清楚——**评语没来不代表成绩丢了**，数字部分是当场就有的。AI 写不出漂亮评语时，那两句会用离线规则给（页面上有降级横幅，不藏着）。
   - **以前那种"收工之后一片转圈 + 红字 timeout"**，根子在总评那次调用没预算上限——生产上实测烧 68 秒，而手机的 30 秒连接早就断了。现在那一段整体挪到了后台。
   - **收工只能点一次**：确认键在请求发出那一刻就禁用，慢网络下反复猛点不会再堆出好几个请求（旧版就是这么产生"收工失败"连环红字的）。

## 练完还想再看那份报告（v2.2.0 修的一个坑）

练完退出后想再看总评：
- **课程详情页 → 「查看上次复盘」**（在「再练一次（新开一局）」旁边，另一颗键、另一句话）→ 直达那场练习的复盘页。
- **首页 → 「最近复盘」** → 你最近练完的那一课的复盘页。

修好之前这里只有一颗「开始学习」，而它其实找不到已经打完的场——点下去是**新开一局**，顺手把刚写好的那份报告留在原地看不见了。所以现在那颗主按钮在这种场合会自己写清楚「再练一次（新开一局）」：看旧报告和开新局是两颗分开的键。

（历史页里的练课记录仍是"练过哪一课、每句多少分"那一份，它跟复盘页**回不去彼此**——复盘页要的那份报告按课时存在会话里，历史行里没有会话编号，本版刻意没加这个字段。）

## 关于"跳过这一步"那行字

打基础页底部那行字以前只有一个布尔在驱动，于是一松手进入评分的整个几十秒里，它会写成"**跳过额度已用完**"，而同屏右上角明明还印着"跳过额度 2/2"——就是你报的那条误报。现在它按真实原因各说一句：评分中就写「评分中…」，全部步骤做完了写「全部步骤已完成」，额度真的用完才写「跳过额度已用完 (每场 2 次)」；而清单还没拿到手时**这一行干脆不出现**。额度本身的规则没变：每场课最多跳 2 步，第三次会挡下来并告诉你原因（这句原因是客户端翻成中文的，不再丢一句英文给你）。

## 词汇 Tab

- **表达库**：你在所有对话里 ⭐ 收藏的地道说法——开会前听一遍自己存的好句子；离线也能看；不再需要可删。
- **弱词生词训练**：任何评分里 <70 分的单词自动进本，逐词听示范→读→≥85 自动「毕业」出本（发音短板专项清零）。

## 我的 Tab

- **能力画像**（雷达图 + CEFR 等级 + **7/30/90 天趋势线**）：你的每一次跟读/实战/测评都在这里悄悄更新——弱在哪一维、这周涨了多少，不用凭感觉。
- **练习历史**：按书名/课名显示每轮成绩（不再是一行天书编号）；点进去看逐句细节。
- **连续天数 + 平均分 + 最高分**：你的练习打卡账本。
- **设置**：后端地址已内置生产地址（除非你要连开发机，否则别动）；发音人选 Mia（美音）/Chloe/Milo/Dean；LLM 可选模型（实战判分/生成/测评恒用服务端统一口径）。

## 老功能仍在原位

课本书（商务/新概念）四模式：**跟读**（逐句评分 ≥60 过关，**长按**录音）、**影子跟读**（整篇连播跟读，**点按**开始/结束 + 已录计时；记得戴耳机——不戴会拾到外放导致虚高分，页内已提醒）、**角色对话**（A 播 B 你读，**长按**录音）、**自由对话**（9 个话题，**点按**开始/结束，30 秒到点自动发；AI 聊天 + IAT 听写 + 润色 + 评分，同实战课一样有「让这句更地道」）。练完那一屏的总分页现在也**不怕被系统杀掉进程**——数据会落一份在应用自己的目录里，重开还在（v2.2.0 前它会整屏丢）。

## 诚实提示（你会看到什么标签）

- 绿色徽 = 真实评测链；灰条/「占位假分」「占位音频」提示 = 该服务未配密钥的占位链路（练习流程/LLM 评分/AI 对话都真；仅**发音打分**和**示范声**需等服务器配讯飞/MiMo 密钥才变真）。占位数据**不会**灌进能力画像——宁缺勿滥。
- 生成新课/测评判级转圈久一点 = 免费额度限速，属预期，切后台不丢进度。
- **「本场没有可信评分证据 (外部评测 / LLM 判分未参与), 总分与四维留空 —— 不是练得差」**：这句话的意思是——这一场**没有可采信的打分来源**（外部评测没参与、LLM 判分也没跑成，或整场都用了跳过），所以总分和四维**故意空着**。它**不是**零分，也**不是**你考砸了：以前这种场合只会给你一个孤零零的破折号"—"，很多人读成了"我考了 0 分"。四维进度条上某几维空着同理——那一维这一轮没证据，画个 0 就是白扣你的分。
- **AI 评语有时就是不给力**：那两句亮点/改进建议出自一次限时的大模型调用。要是它没在期限内给出，页面会用离线规则把两句补齐并挂一条降级横幅——数字部分不受影响。这一版改的是**不再让你干等**（旧版这里会让你看一整页转圈加一个英文 "timeout"），不是"每次都保证有 AI 文案"：这台服务器现役的是免费额度模型，一次 500 字的评语调用**常常**仍会落到离线规则那一路，只是它现在会**在预算内**落，而不是 68 秒才落。
- 屏幕上的错误提示一律是中文：能对上号的后端错误码走一张中文表（包括此前完全没翻译的"跳过额度已用完"），对不上号但后端本来就写了中文的照用，两者都不成时给你一句中文兜底——**不会再把 `timeout` 这类英文原文甩到脸上**。后端返回的原文本身仍是英文（那是对外契约，本次刻意没动）。

## 数据在哪

服务端 PostgreSQL（练习历史/画像/表达库/生成课按设备号归属），录音只用于评分后即删，语音文件不进库。重装 App 同一设备继续累积；换机把旧机「我的-设置」里的设备号填进新机即可接档。

——练习闭环：**选场景 → 打基础 → 实战通关 → 复盘 → 画像更新 → 明天推更弱的**。
