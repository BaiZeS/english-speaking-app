# 使用指南 · English Assistant v2.1.0

> 15 秒版：每天 10 分钟——跟着**任务通关课**把真实场景（英文会议/汇报/谈判）练到敢开口，AI 会像真人一样追问；**5 分钟 CEFR 测评**定级，之后**每次练习都会更新你的能力画像**，进步看得见。

## 安装升级（一次性）

旧版（1.4.0 等）收不到 OTA 提示属预期——装一次新包即可，此后自动更新：
1. 手机浏览器打开（或在 GitHub Releases 页找 `v2.1.0`）：
   `https://github.com/BaiZeS/english-speaking-app/releases/download/v2.1.0/EnglishAssistant-2.1.0.apk`
2. 安装时允许「未知来源」。首次启动不需要任何设置，直接可用。
3. 之后开 App 若提示新版本 → 点更新 → 下载走服务器加速（不再是 GitHub 龟速），装完即最新版。

## 首页（4 个 Tab 之一：首页 / 课程 / 词汇 / 我的）

- **未测评前**：置顶一张「5 分钟测出你的英语水平」引导卡 → 先点它（7 题：跟读/复述/翻译/开放问答，可录音可打字，约 1-2 分钟判级）。定级 A1-C2 + 四维雷达，存到「我的」。
- **继续学习**：上次没练完的课一键续上（崩溃/切后台也不怕）。
- **今日推荐**：自动挑你最弱维度的课。
- **生成我的专属课**：场景画廊入口旁最显眼那张卡。点进去**用一句话说目标**（如「下周主持项目进度会」），进度动画约 3-8 分钟（服务器免费额度限速，泡杯茶回来就在了），生成后进你的课程列表可反复练、可删。
- **场景画廊**：日常交流 / 职场商务 / 考试面试 / 旅行出国 → 8 门人工精编情景课（咖啡店点单、英文项目汇报、协商交付日期、EMBA 面谈…），卡片上有时长/任务数/通关徽章。

## 一门情景课怎么走（核心玩法，约 8-12 分钟）

1. **打基础**：6 步小题——跟读（读句子打分）、复述（用英文总结）、翻译（中译英）、造句（用核心词造一句）。可以跳过 ≤2 步。
2. **任务实战**（像微信聊天）：AI 扮演客户/面试官/老板，**你的屏幕顶部挂着任务清单**（如「问到 deadline」「顶住提前 3 天的压力」「给出可行方案」）——没做到会追问你，做完自动打勾；全部勾完才算**通关**。说得不标准/不地道时，你消息下方冒出「让这句更地道」→ 展开看到**原话 vs 地道说法**对照，点 ⭐ 收进表达库。卡壳点「要提示」拿示范句（会计入复盘评价）。轮次到了自动收工。
3. **复盘报告**：总分 + 发音/语法/词汇/流利度四维条 + 「能力画像 +x.x」增量 + 你的亮点句 / 建议改进 + 每句「你当时说的 vs 更好的说法」+ 参考剧本（可播标准音再学一遍）。有中断的课下次进会弹「上次练了 4 步 / 任务完成 1/4？」一键接上。

## 词汇 Tab

- **表达库**：你在所有对话里 ⭐ 收藏的地道说法——开会前听一遍自己存的好句子；离线也能看；不再需要可删。
- **弱词生词训练**：任何评分里 <70 分的单词自动进本，逐词听示范→读→≥85 自动「毕业」出本（发音短板专项清零）。

## 我的 Tab

- **能力画像**（雷达图 + CEFR 等级 + **7/30/90 天趋势线**）：你的每一次跟读/实战/测评都在这里悄悄更新——弱在哪一维、这周涨了多少，不用凭感觉。
- **练习历史**：按书名/课名显示每轮成绩（不再是一行天书编号）；点进去看逐句细节。
- **连续天数 + 平均分 + 最高分**：你的练习打卡账本。
- **设置**：后端地址已内置生产地址（除非你要连开发机，否则别动）；发音人选 Mia（美音）/Chloe/Milo/Dean；LLM 可选模型（实战判分/生成/测评恒用服务端统一口径）。

## 老功能仍在原位

课本书（商务/新概念）四模式：**跟读**（逐句评分 ≥60 过关）、**影子跟读**（整篇连播跟读，记得戴耳机——不戴会拾到外放导致虚高分，页内已提醒）、**角色对话**（A 播 B 你读）、**自由对话**（9 个话题，AI 聊天 + IAT 听写 + 润色 + 评分，同实战课一样有「让这句更地道」）。

## 诚实提示（你会看到什么标签）

- 绿色徽 = 真实评测链；灰条/「占位假分」「占位音频」提示 = 该服务未配密钥的占位链路（练习流程/LLM 评分/AI 对话都真；仅**发音打分**和**示范声**需等服务器配讯飞/MiMo 密钥才变真）。占位数据**不会**灌进能力画像——宁缺勿滥。
- 生成新课/测评判级转圈久一点 = 免费额度限速，属预期，切后台不丢进度。

## 数据在哪

服务端 PostgreSQL（练习历史/画像/表达库/生成课按设备号归属），录音只用于评分后即删，语音文件不进库。重装 App 同一设备继续累积；换机把旧机「我的-设置」里的设备号填进新机即可接档。

——练习闭环：**选场景 → 打基础 → 实战通关 → 复盘 → 画像更新 → 明天推更弱的**。
